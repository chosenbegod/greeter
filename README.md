# greeter

Это скрипт для вывода приветсвия. принимает имя по аргументу и выводит "Здраствуй, <имя>!".

## Запуск

```bash
./greet.sh Кирилл
```

$1 - Имя

Пишем в первый аргумент имя, вывод фразы.

## Коды возврата
| Код | Значение |
|-----|----------|
| 0 | успех: фраза выведена |
| 1 | не задано имя ($1) |
